## 2026년 11월 27일 결정 (서비스 점검 후속, [FE #76](https://github.com/SW-odyssey/FE/issues/76))

확정:

- 지역은 서버 `areas`의 ID·중심 좌표를 쓴다. 명동을 노출하고 북촌은 서비스 지역에서 뺀다. `전체 지역`은 논리 옵션이다(#77).
- 지역 탐색은 `area-recommendations`의 전체 수·페이지를, 지도 재검색과 내 위치는 반경 300m `recommendations`를 쓰며 화면에 두 의미를 구분해 표시한다(#78, #88).
- 상호 검색은 서버 `place-search`만 쓰고 정적 사전을 두지 않는다. 250ms 입력 대기와 IME 조합 대기(#79).
- 운영 상세에는 샘플 장소·소개·출처를 섞지 않는다. 샘플은 `/guide` 전용(#80).
- 자동 시간은 `slotWindows`를 따르고 빈 구간에는 다음 시간대를 안내한다. 자정~01:00은 전날 심야(#87).
- 언어 변경은 코스를 다시 계산하지 않는다(#85). 코스 이유는 서버 순서의 앞 두 개를 코스 카드에 표시한다(#83).
- 2026-11-28: 장소 목록·지도 목록의 카드에는 50m 칸의 추천 이유(`cells/reasons`, 최대 두 개)를 표시하고, 장소 상세에는 표시하지 않는다(#83 후속). 메인 캐러셀은 그대로 둔다.
- 사진·요약은 유료 호출 전에 요청 한도를 적용하고, 브라우저·서버가 같은 이름의 API 주소 변수를 쓴다(#81, #82). 장소 기본 정보만 60초 공유한다(#86).

## 2026년 10월 31일 UI 결정

- 기존 색감, 유리 표면, Pretendard와 Nunito 및 2줄 상단 구성 유지.
- 대표 추천 최대 5곳을 캐러셀로 표시. 사진 전체를 눌러 상세 진입. 사진 안쪽 하단 점만 표시하며 화살표와 재생 제어는 제거.
- 장소 카드와 목록에는 공간 조건과 추천 이유를 덧붙이지 않고 장소명, 유형과 지역만 표시. (2026-11-28: 목록 카드의 칸 추천 이유는 다시 표시하기로 변경, 위 #83 후속 참고)
- 적용 조건은 추가 줄 대신 필터 버튼 오른쪽 위의 작은 점으로 표시.
- 날짜 휠은 월간 달력으로 교체. 지원 날짜는 서울 오늘부터 6일 뒤까지 유지. 시간대는 한 줄 4구간 세그먼트와 선택 구간으로 표시.
- AI 매장 소개는 AI 추천 분석으로 전환. 표나 펼치기 없이 공간 조건과 시간대의 추천 근거를 짧은 문장으로 표시. 보조 안내 문구는 제거하며 데이터의 예시 여부는 공급부의 provenance와 개발 문서에 보존. 기존 서버 계약에 분석 필드가 구현됐다고 가정하지 않음.
- 상세 복귀는 실제 이전 방문 기록 사용. 직접 링크에는 목록으로 교체하는 대체 동작 제공.

## 2026년 11월 13일 UI 결정

[FE #37](https://github.com/SW-odyssey/FE/issues/37). 10월 31일 결정 중 색감, 유리 표면, 상단 2줄 구성은 아래 기준으로 대체한다.

- 따뜻한 오프화이트 바탕과 흰 카드, 무채색 글자. 포인트 색은 로고의 진한 보라 `#4a1db0` 하나만 쓰고 연한 보라 면은 쓰지 않음.
- 모서리는 `--r-sm` 8px, `--r-md` 12px, `--r-lg` 20px 세 단계. 검색, 언어, 하단 탭처럼 혼자 떠 있는 조작 요소는 캡슐.
- 유리는 지도와 목록 위에 떠 있는 요소(검색, 하단 탭, 지도 도구, 시트)만. 가장자리 반사광은 모든 브라우저, SVG 굴절은 Chromium에서만 적용.
- 상단은 검색, 지역·시간·필터 캡슐, 카테고리 칩의 세 줄. 장소·지도 탭이 같은 위치와 폭을 쓰고, 좌우 여백은 `--local-content-gutter` 하나로 맞춤.
- 지역 선택 아이콘은 로고 심볼. 장소·지도 전환은 선택 표시 240ms, 내용 180ms.
- 상세는 사진 위로 겹치는 흰 시트, AI 추천 분석, 장소 소개와 출처, 위치, 하단 고정 "지도에서 보기". 데이터에 없는 평점·영업시간·거리는 표시하지 않음.
- `/guide` 기기 프레임은 실제 웹 레이아웃을 그대로 사용.
