# LOCAL 프론트엔드 개발 기준

## 실행 기준

| 항목          | 현재 상태                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------ |
| 서비스        | LOCAL, 팀 오디세이                                                                               |
| 용도          | 모바일 퍼스트 웹 UI와 화면 시안 공유                                                             |
| 클라이언트    | Next.js, React, TypeScript                                                                       |
| 시작 화면     | 추천 목록, 기본 지역 종로                                                                        |
| 데이터 공급부 | 운영 `liveDiscoveryDataSource`(Odyssey v2), `/guide`는 `previewDataSource` 샘플                  |
| 조회 경계     | `DiscoveryDataSource.query()`·`queryNext()`·`getPlace()`                                         |
| HTTP          | v2 메타·지역 탐색·주변 추천·상호 검색·상세·그래프·코스, [API_INTEGRATION.md](API_INTEGRATION.md) |
| 지도          | Google Maps, 로드 실패 시 Kakao                                                                  |

`/`는 모바일 퍼스트 웹 앱으로 진입한다. `/guide`와 `/design/tools/place-recommendation`은 기기 프레임에 같은 UI를 표시한다.

| 필터             | 밀도 단일 선택, 컨셉 복수 선택, 결과 수 미리보기        | `FilterSheet.tsx`                                   |
| 지역             | 전체와 서버 메타의 종로, 익선동, 인사동, 을지로, 명동   | `AreaSheet.tsx`                                     |
| 방문 시간        | 월간 달력과 4구간 세그먼트, 조건 바와 필터 경유 구분    | `VisitTimeSheet.tsx`, `VisitCalendar.tsx`           |
| 장소 상세        | 사진, AI 추천 분석, 주소와 출처, 지도에서 보기          | `PlaceDetail.tsx`, `PhotoGallery.tsx`               |
| 지도와 셀 목록   | 배율별 묶음, 50m 예시 셀과 장소 핀, 선택 셀의 장소 목록 | `MapScreen.tsx`, `ExploreMap.tsx`, `PlaceSheet.tsx` |
| 언어             | 한국어, 영어, 일본어, 중국어 UI 사전                    | `LanguageSheet.tsx`, `localization.ts`              |
| 복귀             | 적용 조건, 읽던 위치와 지도 탐색 상태 복원              | `useDiscoveryController.ts`, `preview-url.ts`       |

컴포넌트는 `src/features/discovery/components/`, 지도는 `src/features/map/`에 있다.

| 상태                  | 사용처                                                                          |
| --------------------- | ------------------------------------------------------------------------------- |
| 적용 조건             | 목록, 지도와 결과 수                                                            |
| 필터 임시값           | 필터와 필터에서 연 방문 시간, 개수 미리보기                                     |
| 최종 적용             | 장소 N곳 보기에서 조건을 함께 반영                                              |
| URL                   | 화면, 지역, 장소 ID, 언어, 검색어, 카테고리, 일시, 밀도, 컨셉, 패널과 시트 높이 |
| 언어 우선순위         | URL, 유효한 저장값, 영어 기본값                                                 |
| 요청 날짜와 자동 슬롯 | `visitDate()`와 `seoulHour()`의 Asia/Seoul 기준                                 |
| 지도 시트             | 접힘 88px, 중간 320px, 전체 500px 기준, 웹 앱 높이에 맞춰 조정                  |

지도에서 내 위치 버튼을 누르면 브라우저 위치 권한을 요청하고, 확인한 위치에 점을 표시한 뒤 화면을 그 위치로 이동한다. 지역 선택의 프리뷰 동작과 추천 조건은 별개다.

대표 추천은 상위 최대 5곳을 6초 간격으로 보여주는 캐러셀이다. 사진 전체를 누르면 상세로 이동하며 사진 안 하단의 점, 스와이프와 방향키로 전환한다. 화살표와 재생 버튼은 두지 않는다. 호버, 포커스, 시트 표시와 백그라운드에서는 멈추고 동작 줄이기 설정에서는 자동 전환하지 않는다.

상단은 검색, 지역·시간·필터 캡슐, 카테고리 칩의 세 줄이며 장소와 지도 탭에서 같은 위치와 폭을 쓴다. 밀도 또는 공간 조건을 적용하면 필터 버튼 오른쪽 위에 작은 점을 표시하고 별도 조건 칩 줄을 추가하지 않는다. 날짜는 오늘부터 6일 뒤까지 활성화하며 월 경계를 이동할 수 있다.

상세의 AI 추천 분석은 추천 응답의 선택적 `analyses` 화면 모델을 사용한다. 기본 공급부는 장소 소개와 사진의 공간 태그, 시간대와 분위기 예시를 비교해 근거를 구성한다. 항목표와 펼치기, 보조 안내 문구 없이 짧은 근거 문장만 표시하며 실제 인구 밀도, 실시간 혼잡도, 영업 여부나 AI 점수로 해석하지 않는다. 실제 공급부가 근거를 제공하지 않으면 임의로 보충하지 않는다.

상세 진입은 방문 기록을 추가하고 상세의 뒤로가기는 진입 전 기록으로 이동한다. 직접 상세 링크는 목록 주소로 기록을 교체한다. 닫은 상세가 브라우저 뒤로가기로 다시 나타나는 중복 기록을 만들지 않는다.

## 샘플과 데이터 해석

| 항목        | 해석과 연결 기준                                                  |
| ----------- | ----------------------------------------------------------------- |
| 추천 목록   | 로컬 장소 fixture에 검색, 지역, 카테고리와 샘플 추천 조건 적용    |
| 방문 날짜   | 조회 모델에 전달, 샘플 추천 순서는 시간 슬롯과 샘플 조건으로 재현 |
| 사진과 소개 | 로컬 사진 manifest, 준비된 소개와 요약 문구 및 출처               |
| 지도 숫자   | 현재 조건에 맞는 장소 수                                          |
| 50m 예시 셀 | `previewCell()`이 장소 좌표로 생성한 예시 격자                    |
| LG U+ 자료  | 지역 단위 인구 지표, 실제 제공 필드와 집계 단위 확인 후 연결      |
| 원본 자료   | 출처, 관측 기간, 좌표계, 원해상도와 결측 구분 유지                |
| 매장 정보   | 장소별 출처와 좌표로 연결, 매장 방문량 표시는 별도 근거 확보      |

샘플 공급부와 실제 데이터 공급부를 구분하고, 연결 검수에는 사용한 데이터 버전을 기록한다.

## BE 연결 기준

운영 화면은 Odyssey v2 API를 씁니다. 경로·요청 규칙·환경 변수와 확인 중인 항목은 [API_INTEGRATION.md](API_INTEGRATION.md), 결정은 [DECISIONS.md](DECISIONS.md)에 있습니다. 응답 필드는 [BE #104](https://github.com/SW-odyssey/BE/pull/104)의 유지 계약을 따릅니다.

메인 캐러셀과 장소 목록, 지도 목록에는 한옥 같은 공간 조건이나 추천 이유를 덧붙이지 않는다. 장소명, 유형과 지역으로 구성한다. 코스 카드는 서버 추천 이유의 앞 두 개를 표시한다.
